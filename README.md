# Inner Adventure

## 프로젝트 소개
Inner Adventure는 취미를 찾고 싶지만 쉽게 시작하지 못하는 사용자를 위한 취미 온보딩 서비스입니다.

## Core Value
가치있는 시간을 보낼 수 있게 한다.

## Core Feature
**첫 행동 퀘스트**
탐색, 할거리, 저장및남기기까지 하나로 모아서 가치있는 시간까지의 장벽을 낮춤

## Main Features

사용자 기본 정보 입력
성향 기반 온보딩 질문
시간, 예산, 위치, 에너지 수준을 반영한 취미 추천
추천 취미 카드 제공
취미별 단계형 퀘스트 제공
링크 또는 메모 입력을 통한 미션 완료
진행도, 칭호, 업적 시스템
AI 기반 미션 가이드 생성

## Service Flow

1. 사용자가 이름, 나이, 성별, 거주지 등 기본 정보를 입력한다.
2. 온보딩 질문을 통해 사용자의 성향과 현실 조건을 파악한다.
3. 사용자의 답변을 바탕으로 어울리는 취미를 추천한다.
4. 사용자는 추천된 취미 중 하나를 선택한다.
5. 선택한 취미는 단계별 퀘스트로 전환된다.
6. 사용자는 링크 저장이나 메모 작성 같은 실행 기록을 남기며 미션을 완료한다.
7. 완료 기록은 진행도, 칭호, 업적에 반영된다.
8. 사용자는 작은 행동을 반복하며 취미를 실제 생활 속 활동으로 발전시킨다.

## Installation

```bash
git clone -b feature/ai https://github.com/2023148019/swai.git
cd swai

```bash
npm install
```

```bash
npm run dev
```

AI 기능까지 로컬에서 확인하려면 아래와 같이 해야함.

```bash
npx netlify dev
```

실행 후 터미널에 표시되는 로컬 주소로 접속하면 프로젝트를 확인할 수 있습니다.

## Environment Variables

AI 미션 가이드 기능을 사용하려면 Gemini API 키가 필요합니다.
프로젝트 루트 폴더에 `.env` 파일을 만들고 다음 값을 입력합니다.

```env
GEMINI_API_KEY=your_gemini_api_key
```
